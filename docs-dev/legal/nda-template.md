# 保密协议（NDA）模板

> 用途：意向合作者在签署 CLA 之前，获准查看《回忆》闭源核心的设计方案时签署。
> 与 CLA 的区别：NDA 仅约定保密义务（可看不可说），不涉及任何版权转让；CLA 才是合作后的贡献协议。
> 签署件私藏归档；本文件为公开模板。⚠️ 不构成法律意见。

---

## 《回忆》项目保密协议

本协议由以下双方于 <日期> 签订：

**披露方**：dslsdzc（《回忆》整合包作者）〔签署前替换为真实姓名/主体〕
**接收方**：<意向合作者姓名/主体>

### 1. 保密信息

"保密信息"指披露方向接收方披露的、与《回忆》闭源核心（统一计算引擎、Mixin 注入层、注册窗口、角色调度系统、AI 集成等）相关的以下材料：

- 技术方案文档、架构图、设计说明
- 目录结构、模块清单、接口概述
- 演示材料与讨论内容
- 以口头或书面形式披露并明确标注"保密"的任何信息

不包括：签署前已公开的信息；接收方独立开发获得的信息；依法须披露的信息。

### 2. 保密义务

接收方承诺：

1. 不向任何第三方披露、复制、散布保密信息；
2. 仅在"评估是否与披露方合作"之目的下使用保密信息；
3. 对保密信息采取与保护自身同等机密信息相同的保护措施；
4. 评估结束（或披露方要求）时，销毁或返还全部保密信息及其副本。

### 3. 期限

保密义务自本协议签署之日起生效，持续 **3 年**；若双方后续签署 CLA 并建立合作，本协议保密义务仍独立存续至期满。

### 4. 例外

以下情形不视为违反本协议：

- 信息已进入公有领域（非因接收方过错）；
- 接收方在披露前已合法持有；
- 依据法律、法规或司法程序要求披露（须事先通知披露方）。

### 5. 违约责任

违反本协议给披露方造成损失的，接收方应承担赔偿责任（含披露方为维权支出的合理费用）。

### 6. 适用法律与争议

本协议适用**中华人民共和国**法律。争议先行协商，协商不成提交**披露方住所地有管辖权的人民法院**。
