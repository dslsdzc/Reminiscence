# 支线与世界事件

## 支线完整清单 v1（26 条）

**主线 = 模组内容网 + 星系推进**（匠魂/暮色/AE2 等模组深玩是主线的一部分，不是支线）。支线 = 特殊内容。

- **角色线 6 条**：核心四元线（Herobrine 七形态/303/Null/Slenderman 个人事件链）· 衍生系线（Red/Green Steve、Alexbrine 等）· 村民系线（村庄消失之谜）· 怪物系线（异变线索）· 恐怖传说系（11 号唱片/洞穴音效/边境守卫拼图）· 文化系线（Slender/SCP-173/Lick/天选者致敬剧情）
- **星系线 5 条**：虚无星系探索拆 3（AOA 枢纽/维度图鉴/维度 Boss）· 传说行星 2（史诗行星/终焉遗迹）
- **考古线 8 条**：命运行星历史碎片——暮色/以太/阿图姆/交错/深渊/恐惧/埃里伯斯/午夜各一套壁画笔记
- **经营图鉴 3 条**：星际补给线（空间站建设）· 星际贸易线（跨行星经济）· 星图收藏（全档案点亮）
- **隐藏事件 4 条**：隐藏 Boss 星 ×4（内环/中环/外环/深空）· 隐藏次级入口（纯发现）· 世界事件线（泰坦/风暴，见下）· 感染线（见下）

原则：零强制、无追踪器、发现靠线索、与主线无材料卡点关系（可选加速）、完成度不参与终局判定。

## 世界事件系统（注册式事件框架）

事件型内容不独立成星、随时可触发、无任务书提示——事件"降临"而非"被接取"。**设计为注册式框架**：事件注册表 + 调度器（按权重抽事件/触发时机/冲突处理），事件 = 配置 + 钩子（新事件 = 新配置，不动框架）——3 个起点事件，实际会随时增加。

**起点事件**：

| 事件 | 触发 | 过程 | 产出 |
|---|---|---|---|
| 泰坦召唤 | 材料仪式（召唤石+条件）| 泰坦降临 → 猎杀（AI 走 PathService C 层，TPS 保护）| 泰坦材料（装备线）|
| 凋灵风暴 | 终局级仪式（多维材料）| 风暴生成 → 阶段战（可多次）| 风暴核心（终局材料）|
| 感染爆发 | 每 N 游戏日概率触发于程序生成行星 | 生物异变 → 星图"感染信号"线索 → 玩家响应清理 | 净化材料（附魔/药剂线）|

**候选扩展**（框架就绪后随时加）：陨石雨 / 日食 / 血月（与满月纪念碑联动设计）/ 维度裂缝 / 虫潮 / 太空风暴……

**联动**：事件触发 = 星图异常线索（可发现性系统，无弹窗）；感染爆发时角色可协助；事件不参与终局判定；清感染多 = 爆发少（平衡反馈）。
