# 《回忆》（Reminiscence）整合包设计文档 v1

> 日期：2026-07-31
> 状态：已确认设计的综合规格。定制机制（统一引擎）与支线细节标注为"待深化"。

## 1. 项目定位与核心哲学

一个 1.12.2 + Cleanroom（Java 21）的巨型整合包：**"小时候在视频里看过、服务器里玩过、朋友家见过的模组，这里全都有——但它们被重新编织成一张网。"**

- 无任务书、无进度追踪器、无弹窗提示
- 进度由**材料卡点**自然产生：想合成 → 缺材料 → 自己探索去哪找 → 火箭 → 行星 → 维度 → 回来
- 玩家只需要做一件事：继续玩下去

## 2. 四层架构总览

## 3. 主线设计（第三层）

### 3.1 星系分层

- **家园系**：主世界 → 月球(0.3 AU) → 火星(1.5 AU) → 小行星带(2.8 AU)——教学链（氧气/重力/燃料/火箭）
- **命运行星**（手工设计 20-30 颗，每颗 = 一个经典维度模组）：暮色星/以太星/阿图姆星/交错星/深渊星/恐惧星/埃里伯斯星/午夜星 + 后续按模组清单扩充
- **程序生成外域**（30-80 颗，种子驱动自动生成）：无名行星、环境参数、资源分布、遗迹、稀有度分级——生成算法放 C 引擎（性能 + 护城河）
- **空间站层**（3 个）：轨道站 / 深空中继 / 外围总站——导航、补给、部分维度入口
- **虚无星系（AOA）**：独立支线星系，极远 AU，跳板链可达，内部按 AOA 原生体系探索——不进主线

规模：手工 20-30 + 生成 30-80 = **50-100+ 行星**。

### 3.2 航行系统（AU 制）

- 距离单位 **AU**（游戏化数值）
- **火箭等级 = 每跳最大航程（AU）**：一级火箭 ≤3 AU，逐级放开——星图是开放图，方向自由，任意已解锁行星为起点，目标在航程内即可跳（一级火箭也能一路跳板链到虚无星系）
- 燃料等级（初级→中级→高级→奇点）：能量密度递增，配方材料散落在不同行星
- 软卡点：燃料/防护装备（配方依赖）
- 空间站中继：航程不足分段飞

### 3.3 命运行星清单（已确认 8 + 扩充位）

| 行星 | 模组 | 环位 | 核心产出 |
|---|---|---|---|
| 暮色星 | 暮色森林 | 内环 | 灵魂碎片（奇点前置） |
| 以太星 | 以太天堂 | 内环 | 飞行/附魔材料 |
| 阿图姆星 | Atum | 中环 | EMC 放大器 |
| 交错星 | Betweenlands | 中环 | 核电燃料化学线 |
| 深渊星 | AbyssalCraft | 中环 | 血魔法前置 |
| 恐惧星 | The Abyss II | 外环 | 恐怖系材料 |
| 埃里伯斯星 | Erebus | 外环 | 生物科技 |
| 午夜星 | The Midnight | 深空 | 高阶神秘学 |

结构类模组（失落城市/冰与火等）不独立成星，作为行星表面内容层；半维度模组并入行星做次级入口。

### 3.4 材料卡点与可发现性

- **无阶段、无时代**——只有配方依赖（统一引擎接管配方，缺维度材料无法合成）
- **可发现性 = 星图模糊线索 + 世界碎片线索**：
  - 星图：未探索行星显示模糊提示（"富含未知矿物"/"信号异常"/"灵异信号"），探索后具体化
  - 世界碎片：地牢壁画、村庄笔记、角色低语——拼线索
- 不用 JEI 来源标注、不用概率性获取

### 3.5 终局

- 条件：全行星登陆 + 全维度进入 + 全部角色至少成功调度一次
- 纪念碑：**主世界家园，满月之夜**自动生成，刻所有角色名，预设计结构随包发布
- 此后世界不再产生新变化

## 4. 支线体系

**主线 = 模组内容网 + 星系推进**（匠魂/暮色/AE2 等模组深玩是主线的一部分，不是支线）。

**支线 = 特殊内容**（目标 20-30 条，待深化）：
- 角色个人线 ×53（每角色事件链）
- 虚无星系探索（AOA 多维）
- 传说行星分级线 / 每环隐藏 Boss 星 ×4
- 命运行星考古碎片线（按行星拆）
- 星际补给/贸易线、星图收藏图鉴、隐藏次级入口

支线零强制、无追踪器、发现靠线索、与主线无材料卡点关系（可选加速），完成度不参与终局判定。

## 6. 定制机制（第二层，待深化）

### 6.1 统一计算引擎（框架）

C 语言核心 + JNI 供 Java 模组调用。被接管模块：
- 等价交换 EMC 递归网络
- AE2 自动合成路径搜索
- 泰坦生物伤害结算
- 龙之进化护盾能耗曲线
- 血魔法祭坛多线程叠加

参考实现：**Power Converters 代码**（跨能量转换联动网络的参照）。

### 6.2 联动网络（已确认条目，转换率/数据流待深化）

- AE2 存储 ⇄ 星辉魔法星光能量
- 植物魔法魔力 → 通用机械 Joules
- 无尽贪婪奇点 ← 暮色 Boss 灵魂碎片（注入）
- EMC ← 阿图姆金线（放大器）
- 血魔法 ← 深渊星材料 / 核电 ← Betweenlands 化学线 / 生物科技 ← Erebus

目标：形成咬合闭环（A→B→C→A 交叉依赖），无唯一最优路径。

### 6.3 强依赖设计

定制机制不是可选优化，是引擎经 Mixin 层强制接入。核心缺失/替换 → 机制静默失效，包退化成普通模组堆。

全部 MC 圈记忆，零通用都市传说；游戏/影视 IP 类不进入本体系。

### 7.2 架构：注册表 + 适配器

- 角色注册表：53+1 统一注册（名字/阵营/遭遇条件/信任阈值/能力集）
- 每角色适配单元：状态机参数表 + 独有能力钩子 + 专属事件链
- **开源/闭源边界**：适配器参数（内容）公开，调度内核（状态机引擎/仲裁器）闭源
- Herobrine 额外实现七形态切换；另有隐藏第八形态 HIM（终局条件达成后解锁）

### 7.3 调度与界面

- 纯指令调度：`/reminiscence <角色> <指令>`；四种模式：全局广播 / 单角色 / 组合 / 战术（按战斗场景自动分配职能）
- 唯一 UI：**属性面板**（信任度/已获取物/当前能力/位置），按键呼出，不常驻
- 无 HUD、无指挥界面

### 7.4 AI 双模

- 云端：大模型驱动（玩家 API 密钥，**仅存本地配置文件**——玩家文档隐私承诺，实现必须兑现）
- 本地：纯状态机规则驱动（无个性但可用）
- 降级：云端超时/断网自动切本地，行为不中断

### 7.5 成长 = 获取物交付制（星辉魔法式强化）

- 无经验条、无等级、无数值成长
- 每角色 3-5 成长节点（核心能力 1 + 进阶 2-3 + 最终形态 1），每节点 = 一件成长物品（自主线/支线产出），材料+仪式交互交付 → 解锁二元能力
- 53 角色 × ~4 节点 ≈ 200+ 成长物品，全部挂在世界产出上
- 示例：Herobrine ← 幽灵碎片(暮色星)→幽魂传送；303 ← 红石核心(小行星带)→方块操控；Slenderman ← 暗影结晶(深渊星)→精神干扰
- 信任系统：成功任务 +、被伤害 -；低于阈值回归野性需重新遭遇

## 8. 护城河策略

### 8.1 仓库结构（已确认方案 A：双仓库）

- **公开仓库 `Reminiscence`**：pack/(config/scripts/mods清单/manifest) · patches/(开源模组定制 diff) · docs/(玩家) · docs-dev/(公开开发) · build/ · EULA.md
- **私有仓库 `Reminiscence-Core`**：core-native(C引擎) · core-mixin(Mixin注入层) · core-bridge(JVM桥接) · ai-dispatcher(调度内核) · docs/(JNI契约/注入清单/AI设计)
- 对齐：公开仓 manifest.json 声明核心版本号 → 发布流水线注入二进制

### 8.2 三层防线

- **法律**：EULA（禁搬运/逆向/拆包提取）· modlist 逐模组授权标注（CurseForge 要求）· compliance 强制项（AI 实现闭源修改的许可证核查——MIT/Apache 可、GPL 不可）
- **技术**：机制-实现分离（公开 diff 只描述行为）· 强依赖（拆核心=机制消失）· **软校验**（哈希不符 → 提示"非官方修改版" + 机制降级，不拒绝启动）· 渠道指纹（各渠道包嵌不同渠道 ID hash 溯源）· 防逆向（C 引擎 -O2+strip，核心 jar 混淆）
- **流程**：执行者（AI/外包）只接触公开仓 + 单任务 spec · 私有仓双人审查 · 私有 runner 构建闭源产物

### 8.3 泄露防护

公开仓 CI 对 docs/docs-dev 做关键词扫描（内部类名/JNI 签名/钩子类名命中即失败）——防 AI/外包执行者无意泄密。
