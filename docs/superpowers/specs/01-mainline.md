# 主线设计（第三层）

## 星系分层

- **家园系**：主世界 → 月球(0.3 AU) → 火星(1.5 AU) → 小行星带(2.8 AU)——教学链（氧气/重力/燃料/火箭）
- **命运行星**（手工设计 17 颗）：维度星 13 + 内容主题星 4（见下）
- **程序生成外域**（30-80 颗）：种子驱动自动生成，环境参数/资源分布/遗迹/稀有度分级——生成算法放 C 引擎 GenerationService
- **空间站层**（3 个）：轨道站 / 深空中继 / 外围总站——导航、补给、部分维度入口
- **虚无星系（AOA）**：独立支线星系，极远 AU，跳板链可达——不进主线

规模：17 手工 + 1 隐藏 + 2 入口 + 生成 30-80 = 50-100+ 行星。

## 航行系统（AU 制）

- 距离单位 **AU**；**火箭等级 = 每跳最大航程（AU）**（一级 ≤3 AU，逐级放开）
- 星图开放图：任意已解锁行星为起点，目标在航程内自由跳（无路线限制）
- 燃料等级（初级→中级→高级→奇点）：配方材料散落各行星；软卡点：燃料/防护装备
- 空间站中继：航程不足分段飞

**事件型内容不独立成星**：泰坦/凋灵风暴/感染 = 世界事件（见 02 支线与事件）

## 材料卡点表 v2（科技-行星咬合 + 强度）

**实现机制（四层锁）**：
- 配方层（90% 卡点）：CraftTweaker 改配方——高级配方材料替换为维度产物，缺材料 = JEI 灰色 = 合成不了（配方缺材料本身就是锁，无需特殊锁系统）；每条卡点 = 1 个 spec 任务
- 世界层：星图线索 + 世界碎片（JEI 不标注来源，靠线索自找）
- 环境层：AU 航行 + 环境锁（想去拿材料本身被航行系统锁住）
- 引擎层：仅计算型配方（EMC 评估/能量转换）——普通卡点不经引擎

## 可发现性

- 无阶段、无时代——只有配方依赖（统一引擎接管配方）
- **星图模糊线索**：未探索行星显示模糊提示（"富含未知矿物"/"信号异常"/"灵异信号"——灵异信号 = 角色遭遇入口提示），探索后具体化
- **世界碎片线索**：地牢壁画、村庄笔记、角色低语——拼图式引导
- 不用 JEI 来源标注、不用概率性获取

## 终局

- 条件：全行星登陆 + 全维度进入 + 全部角色至少成功调度一次
- 纪念碑：**主世界家园，满月之夜**自动生成，刻所有角色名，预设计结构随包发布
- 此后世界不再产生新变化
