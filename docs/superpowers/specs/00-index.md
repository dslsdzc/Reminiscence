## 项目定位与核心哲学

《回忆》：Minecraft 1.12.2 + Cleanroom（Java 21）巨型整合包——"小时候在视频里看过、服务器里玩过、朋友家见过的模组，这里全都有，但它们被重新编织成一张网"。

- 无任务书、无进度追踪器、无弹窗提示
- 进度由**材料卡点**自然产生（想合成 → 缺材料 → 探索 → 火箭 → 行星 → 维度 → 回来）
- 玩家只需要做一件事：继续玩下去
