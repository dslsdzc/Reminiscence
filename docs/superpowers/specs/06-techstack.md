# 技术栈与内存策略

## 技术栈

- Minecraft 1.12.2 + Cleanroom（Java 21，兼容 Forge 模组）
- C 核心（JNI）→ 计算密集模块（计算运行时 + 服务框架，见 03-customization）
- AI 接入：合作方开源实现修改版（有仓库访问权限），原项目许可证合规检查为强制项
- 能量转换联动参照 Power Converters 源码
- **运行时注册窗口**（旗舰研究组件，见 `2026-07-31-reg-window-design.md`）：模组按需运行时加载，三阶段路线（分量保底 → 注册窗口 MVP → 全量动态加载）；做成后模组数量不受启动内存约束

## 内存策略（3 杠杆）

- **清单瘦身**：1466 → 1338（排除 37 / 去重 79 / 平衡砍 15）
- **分量加载**（阶段 1 保底）：内容域分量 + 解锁触发自动切换配置（重启生效）；6GB = 经典档（约 700 模组），全量档 10-12GB
- **C 化扩展**：计算层移 C（已计划）+ 区块存储 native 化 / 行星生成 / 角色状态机（路线图）——每移一块全量档内存线降一截
